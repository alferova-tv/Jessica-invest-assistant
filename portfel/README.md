# Портфель

Локальный учёт инвестиций по двум брокерским счетам (Т-Инвестиции и Альфа).
Показывает стоимость портфеля, прибыль за всё время и за день, доходность (простую,
как в Snowball, и XIRR), пассивный доход, полученные и ожидаемые выплаты по месяцам
с расшифровкой по бумагам, ближайшие выплаты, лидеров роста и падения за день
и структуру по эмитентам, отраслям, кредитному рейтингу, видам бумаг и годам возврата номинала. По клику на бумагу
открывается её карточка: график цены за год с линией средней цены покупки, купон
и доходности, позиция на каждом счёте, сделки и будущие выплаты.

## Установка и запуск

Сначала установи Jessica и заполни её конфиг по [основной инструкции](../README.md#установка).
Затем из корня репозитория запусти:

```bash
cd portfel
../.venv/bin/python -m portfel sync
../.venv/bin/python -m portfel serve
```

`sync` читает выписки и T-Invest API, получает котировки и сохраняет собственную
локальную базу. Сервер откроет интерфейс на **http://localhost:4343**;
для остановки нажми `Ctrl+C` в терминале. Он слушает только локальный адрес.

Команды из папки `portfel/`:

```bash
../.venv/bin/python -m portfel sync     # обновить данные
../.venv/bin/python -m portfel serve    # открыть интерфейс
../.venv/bin/python -m portfel summary  # показать сводку в терминале
```

У `summary` есть фильтр `--portfolio alpha` или `--portfolio tinkoff`.
Кнопка «Обновить» в интерфейсе делает то же, что `sync`.
Котировки сервер обновляет и сам: раз в 15 минут по будням с 10:00 до 20:00 МСК,
без выписок и T-Invest. Новые цены видны после перезагрузки страницы.

### Автоматический запуск

Вернись в корень репозитория (`cd ..`, если ты в `portfel/`). Создай задачу macOS
из шаблона: пути подставятся автоматически, существующий файл сохранится.

```bash
.venv/bin/python - <<'PYTHON'
import os
import plistlib
from pathlib import Path

project = Path.cwd()
data = Path(os.environ.get("JESSICA_HOME", Path.home() / "Documents/Tracking/Invest")).expanduser().resolve()
(data / "portfel").mkdir(parents=True, exist_ok=True)
agent = Path.home() / "Library/LaunchAgents/com.alferova.portfel.plist"
agent.parent.mkdir(parents=True, exist_ok=True)
text = (project / "portfel/launchd/com.alferova.portfel.plist").read_text()
spec = plistlib.loads(text.encode())
spec["ProgramArguments"][0] = str(project / ".venv/bin/python")
spec["WorkingDirectory"] = str(project / "portfel")
spec["EnvironmentVariables"]["JESSICA_HOME"] = str(data)
spec["StandardOutPath"] = spec["StandardErrorPath"] = str(data / "portfel/server.log")
with agent.open("xb") as stream:
    plistlib.dump(spec, stream)
print(agent)
PYTHON
plutil -lint ~/Library/LaunchAgents/com.alferova.portfel.plist
launchctl bootstrap "gui/$(id -u)" ~/Library/LaunchAgents/com.alferova.portfel.plist
```

Перед включением останови сервер, запущенный вручную. Фоновая задача запускает
сервер сразу и при входе в систему. Остановить её:

```bash
launchctl bootout "gui/$(id -u)" ~/Library/LaunchAgents/com.alferova.portfel.plist
```

Для постоянного отключения после остановки перенеси файл из `LaunchAgents`
в другую папку. Шаблон из репозитория нельзя загружать напрямую: он содержит
заглушки путей.

## Откуда данные

| Что | Источник |
|---|---|
| Сделки, купоны, дивиденды, комиссии Альфы | все xlsx и zip в `~/Documents/Tracking/Invest/alpha/reports/` |
| Операции Т | T-Invest API, токен из `config.yaml` Jessica |
| Цены, НКД, номинал, ISIN по регномеру | ISS Мосбиржи |
| График купонов, амортизаций и погашений | ISS Мосбиржи (`bondization`) |
| Закрытие прошлого дня, купон, доходность к погашению, дюрация | ISS Мосбиржи, вместе с ценами |
| История цены для карточки бумаги | ISS Мосбиржи: за месяц и дольше `history` (кэш на день), за день и неделю — свечи `candles` (10 мин и 1 ч) |
| Отрасль бумаги (вкладка «Структура») | T-Invest API (`BondBy`/`ShareBy`/`EtfBy`), один раз на бумагу, и для бумаг Альфы тоже. Свои правки: СФО → «Секьюритизация», ЭкоНива → «Агро», РЖД и ТрансКонтейнер → «Транспорт» (`SECTOR_FIXES`, `SECTOR_BY_ISSUER` в `model.py`) |
| Кредитный рейтинг облигации (вкладка «Структура», «по риску») | карточка smart-lab `/q/bonds/<ISIN>/`, одна сводная буква без агентства; обновляется при каждой синхронизации, ОФЗ не запрашиваются |
| Сверка количества | `state/holdings.json` Jessica |

Своя база лежит в `~/Documents/Tracking/Invest/portfel/portfel.db` (SQLite). Портфель
только читает файлы Jessica и ничего в них не пишет.

Незавершённые сделки (расчёт после конца периода выписки) тоже загружаются. В следующей
выписке та же сделка приходит завершённой с тем же номером и заменяет незавершённую.

Год погашения у выпусков с амортизацией, прежде всего СФО, берётся из графика `bondization`:
это дата последней ненулевой выплаты номинала. Дата погашения по документам у СФО на несколько
лет позже, к ней номинал уже выплачен. Эта дата идёт в столбец «Погашение», а в карточке бумаги показана строкой «Фактически».

Лесенка «Возврат номинала по годам» на вкладке «Структура» делит стоимость облигации
по годам пропорционально номиналу, который в них вернётся по графику: у ЛСР 60 % номинала
приходит амортизациями в 2028, остальные 40 % погашением в 2029.

Выписки Альфы пересекаются по датам, и это нормально, потому что сделка узнаётся
по номеру, а денежная операция по времени, тексту и сумме. Повторная загрузка ничего
не задваивает.

## Правила расчёта

- Себестоимость считается по средней цене покупки. При продаже списывается средняя
  себестоимость проданных штук, разница идёт в реализованную прибыль.
- НКД в себестоимость не входит. Купоны показаны как пришли и отдельно за вычетом НКД,
  уплаченного при покупке.
- Амортизация уменьшает себестоимость, так как это возврат вложенного. В доходы она не идёт.
- Прибыль = курсовая + реализованная + купоны и дивиденды ± НКД − комиссии − налоги.
- XIRR считается по денежным потокам бумаг. Свободные деньги на счёте в него не входят,
  потому что брокеры не отдают полную историю пополнений.
- Изменение за день — к официальному закрытию прошлого торгового дня.
- Доходность = прибыль за всё время / пополнения счетов за вычетом выводов. «Рост активов» —
  изменение цены бумаг, которые сейчас в портфеле, к средней цене покупки.
- Пассивный доход = купоны и дивиденды, ожидаемые за 12 месяцев, к стоимости портфеля.
- Ожидаемые выплаты считаются по текущему количеству и до НДФЛ. Купон флоатера, который
  ещё не объявлен, взят по последней известной сумме и помечен «оценка».

## Ограничения

- **Входящий остаток Альфы.** Если самая ранняя выписка начинается позже открытия счёта,
  бумаги на её начало берутся по стоимости на эту дату, и цена покупки у них приблизительная
  (метка «остаток»).
  Альфа отдаёт пустой отчёт, если период кончается сегодняшним днём, поэтому конец периода
  нужно ставить на вчера.
- **Выплата в день после выписки.** ISS уменьшает номинал амортизируемой бумаги в день
  выплаты, а деньги видны только в следующей выписке. До неё по такой бумаге висит
  бумажный убыток на сумму амортизации.
- **Купоны после последней выписки** не видны, пока нет новой выписки. Интерфейс пишет,
  по какую дату есть выписки, и отдельно перечисляет дни между выписками, за которые
  выписки нет: сделки этих дней в учёт не попадают, и количество бумаг расходится с брокером.
- **Т без истории сделок.** Если T-Invest ни разу не ответил, состав Т берётся из Jessica
  с себестоимостью, равной текущей стоимости (метка «без сделок»). После первого успешного
  обновления эти строки заменяются настоящими операциями.
- **Фонды на Т.** Jessica не учитывает паи фондов, поэтому «Портфель» исключает
  их из сверки состава с Jessica.
- Прогноза дивидендов по акциям, истории стоимости портфеля и сравнения с индексом нет.
